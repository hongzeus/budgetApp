# budgetApp

가계부 앱 샘플 프로젝트와 개인 포트폴리오·행사 참가 신청 페이지를 함께 담은 저장소입니다.

## 로컬 실행

Node.js가 설치되어 있다면 테스트를 실행할 수 있습니다.

```bash
npm test
```

정적 페이지는 다음 파일을 브라우저로 열어 확인할 수 있습니다.

- `index.html` - 행사 참가 신청 페이지
- `resume-site/index.html` - 홍재선 개인 포트폴리오 홈페이지

## 환경변수

Supabase 연결을 위해 `.env.example`을 참고해 환경변수를 설정합니다. 실제 비밀키는 GitHub에 올리지 않습니다.
